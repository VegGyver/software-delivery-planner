# Task Naming

## Existing convention

```txt
Primary format: B-### — Imperative task title
Examples: B-015 — Define Feature domain model; B-016 — Implement Feature API and backend logic
External tracker: None verified
Sub-step format: Unclear
Change request format: Unclear
Bug-fix format: Unclear
Extension format: Unclear
Refactor format: Unclear
Commit reference format: Conventional commit-style subject; task ID inclusion is not established
```

## Rules

- Preserve and use the existing B-### backlog identifiers.
- Do not rename or reuse historical task IDs.
- Keep task ID, task title and framework task type as separate concepts.
- Create later extensions, fixes, refactors and follow-up work as new linked
  tasks.
- Follow only an approved linked-task naming convention.
- No linked-task naming convention is currently verified; record it as unclear
  rather than inventing one.
